# 🚀 Hermes — Roguelite / Bullet-Heaven 3D Espacial

> [!abstract] Resumo do Projeto
> Jogo 3D *roguelite* / *bullet-heaven* espacial desenvolvido na **Unity 6**, com estética *low-poly* e *pixel-shading*, naves espaciais inspiradas em animais com combate *melee* e GDD formal.

---

## 🎯 Objetivo

Desenvolver um jogo espacial 3D *roguelite* / *bullet-heaven* com identidade visual *low-poly* + *pixel-shading*, sistemas próprios de combate e shaders customizados.

---

## 🛠️ Stack e Arquitetura Técnica

| Componente | Tecnologia / Abordagem |
| --- | --- |
| **Engine** | Unity 6 (C#) |
| **Pipeline Gráfico** | URP (Universal Render Pipeline) |
| **Câmera** | Cinemachine 3 |
| **Shaders** | Shader Graph — shaders próprios de quantização de paleta e *dithering* |
| **Performance** | Object Pooling |
| **Combate & Física** | Colisões de projéteis por *raycast* e combate *melee* |
| **UI / Diegética** | Prompts de interação 3D flutuantes |
| **Design** | GDD formal |

---

## ✅ Funcionalidades Implementadas

- [x] Estética *low-poly* com *pixel-shading*, quantização de paleta e *dithering* via Shader Graph
- [x] Naves espaciais inspiradas em animais com combate *melee*
- [x] Sistema de projéteis com colisão por *raycast* e Object Pooling
- [x] Configuração de câmera com Cinemachine 3
- [x] Prompts de interação 3D flutuantes
- [x] Documento de Game Design (GDD) formal
