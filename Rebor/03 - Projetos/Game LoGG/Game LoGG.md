# 🎮 Game Logg

> [!info] Projeto em Espera
> Mantido em `status: espera` no [[Home|Dashboard]] para respeitar o limite de projetos ativos. Quando quiser priorizar este projeto, altere `status` para `ativo` no topo.

> [!abstract] Resumo do Projeto
> Plataforma social **web e mobile** para acompanhar jogos zerados, platinas, tempo de jogo e avaliações multicritério.

---

## 🎯 Objetivo

Oferecer uma plataforma social completa para registro, acompanhamento e avaliação multicritério de jogos (zerados, platinas e tempo de jogo), integrada a catálogos oficiais.

---

## 🛠️ Stack Técnica

| Camada | Tecnologias |
| --- | --- |
| **Mobile / Front** | React Native, Expo, TypeScript, NativeWind |
| **Backend** | Node.js, Express |
| **ORM & Banco** | Prisma, MongoDB |
| **APIs Externas** | IGDB API, Steam API |
