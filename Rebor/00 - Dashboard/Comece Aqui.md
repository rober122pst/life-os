# 📖 Comece Aqui — Guia Rápido do Life OS

Se você esquecer como mexer em alguma coisa no Obsidian, volte aqui. **O sistema existe para te ajudar, não para virar mais uma obrigação.**

---

## ⚡ Os 4 comandos que você realmente precisa

| O que você quer fazer | Como fazer |
| --- | --- |
| **Abrir qualquer nota rápido** | `Ctrl + O` e digite o nome |
| **Criar uma nota nova (vai direto pro Inbox)** | `Ctrl + N` |
| **Abrir a nota de hoje** | Clique no dia de hoje no **Calendário** (barra direita) ou no ícone de calendário na barra esquerda |
| **Abrir qualquer comando / inserir template** | `Ctrl + P` |

---

## ✅ Como criar uma tarefa que aparece no Dashboard

Em **qualquer nota** do Obsidian (nota diária, projeto, faculdade, estágio), basta escrever:

```markdown
- [ ] Entregar atividade da faculdade 📅 2026-11-26
```

- Quando você digita `- [ ] `, o plugin **Tasks** abre um menu de sugestão para escolher a data e a prioridade (⏫ alta, 🔼 média, 🔽 baixa).
- Não importa em qual pasta a nota esteja: se tiver data de hoje, atrasada ou dos próximos 7 dias, **ela aparece automaticamente na [[Home]]**.

---

## 📥 Surgiu uma ideia no meio de outra tarefa?

**Não pare o que está fazendo para pesquisar ou organizar.**
1. Abra [[Ideias e pensamentos rápidos]] (ou aperte `Ctrl + N` para criar uma nota solta no `01 - Inbox`).
2. Escreva em 1 linha e feche.
3. No fim do dia ou no domingo, você decide se vira tarefa, projeto ou vai pro lixo.

---

## 🚀 Como criar um projeto novo

1. Clique com o botão direito em `03 - Projetos` → **Nova pasta** (ou **Nova nota**).
2. Crie a nota do projeto.
3. Aperte `Ctrl + P` → digite `Templates: Insert template` → escolha **Projeto**.
4. Preencha as propriedades no topo (`status: ativo` para aparecer na tabela principal da [[Home]], ou `status: espera` para deixar na fila).

---

## 🧠 Regra para dias sem energia

Nos dias em que você não tiver cabeça para se organizar:
1. Abra só a [[Home]].
2. Olhe **1 única tarefa** importante.
3. Faça só ela (ou dê o primeiro passo de 5 minutos).
4. Feche o Obsidian sem culpa.

## 🔗 Ecossistema recomendado

- **Obsidian:** *o que* fazer, *por que* fazer e *como* fazer.
- **Google Calendar:** *quando* fazer (horários fixos, provas, reuniões).
- **GitHub:** execução técnica e código dos projetos.
