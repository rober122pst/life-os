# ⚙️ Stack e Sistemas de Game Dev

> [!tip] Filosofia Técnica
> Forte foco em **criar sistemas do zero** (física, *spatial partitioning grids*, *behavior trees*, *raycast* e shaders customizados), sem depender apenas de pacotes prontos.

---

## 🛠️ Engines, Bibliotecas & Versionamento

| Categoria | Tecnologias |
| --- | --- |
| **GameMaker** | GML, shaders GLSL (troca de paleta), pixel art 2D |
| **Unity 6** | C#, URP, Cinemachine 3, Shader Graph, Object Pooling |
| **Web 2D / 3D** | React Three Fiber, HTML5 Canvas |
| **Versionamento & Pipeline** | GitHub, Unity DevOps |

---

## 🧩 Sistemas Implementados do Zero

- **Física customizada** (incluindo perspectiva 2.5D de gol em [[Copa do Mundo 2026 - Mundial da Educação]]).
- **Spatial partitioning grids** para otimização espacial.
- **Behavior Trees** para IA de bots (ex.: formação 1-2-2 em [[Copa do Mundo 2026 - Mundial da Educação]]).
- **Colisões por Raycast & Object Pooling** (ex.: projéteis em [[Jogo espacial|Hermes]]).
- **Shaders próprios:** GLSL para troca de paleta (GameMaker) e Shader Graph para quantização de paleta e *dithering* (Unity 6).
