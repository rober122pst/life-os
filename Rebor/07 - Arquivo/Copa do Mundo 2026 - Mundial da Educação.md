# ⚽ Copa do Mundo 2026: Mundial da Educação

> [!abstract] Resumo do Projeto
> Jogo arcade de futebol 2D em pixel art desenvolvido no **GameMaker** em **junho de 2026** no [[Estágio]] (NTE — Prefeitura de Paulista) para escolas municipais.

---

## 🛠️ Stack e Sistemas Implementados

| Componente | Detalhe Técnico |
| --- | --- |
| **Engine / Linguagem** | GameMaker (GML) |
| **Estilo Visual** | Pixel art 2D |
| **IA dos Bots** | *Behavior trees* com formação tática **1-2-2** |
| **Física** | Física de gol em perspectiva **2.5D** |
| **Shaders** | Shaders **GLSL** de troca de paleta |
| **Conteúdo Educacional** | Trivia de países |
