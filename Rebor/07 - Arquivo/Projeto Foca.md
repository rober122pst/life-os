# 🦭 Projeto Foca

> [!abstract] Resumo do Projeto
> App web **full-stack de produtividade gamificada** desenvolvido entre **novembro e dezembro de 2025**, integrando Pomodoro, rotinas recorrentes no padrão **RFC-5545**, progressão de **XP quadrática** e monitor de janela ativa em Python.

---

## 🛠️ Stack Técnica

| Camada | Tecnologias |
| --- | --- |
| **Frontend** | React, Tailwind CSS, Framer Motion |
| **Backend** | Node.js, Express, Socket.IO |
| **ORM & Banco** | Prisma, PostgreSQL |
| **Agente Desktop** | Monitor de janela ativa em Python |
| **Domínio / Regras** | Pomodoro, rotinas recorrentes (RFC-5545) e progressão de XP quadrática |
