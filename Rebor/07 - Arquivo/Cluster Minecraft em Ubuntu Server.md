# ⛏️ Cluster Minecraft em Ubuntu Server

> [!abstract] Resumo do Projeto
> Cluster de **3 nós** desenvolvido em **maio de 2026** para a disciplina de **Arquitetura de Computadores** ([[Faculdade]]), inicialmente montado em **VirtualBox** e posteriormente migrado para **AWS EC2**, rodando **Velocity proxy** e **PaperMC**.

---

## 🛠️ Arquitetura e Tecnologias

| Componente | Especificação |
| --- | --- |
| **Topologia** | Cluster de 3 nós |
| **Sistema Operacional** | Ubuntu Server |
| **Infraestrutura** | VirtualBox → migrado para **AWS EC2** |
| **Serviços** | **Velocity** (proxy) + **PaperMC** |
| **Disciplina** | Arquitetura de Computadores (ADS — UNINASSAU Paulista) |
