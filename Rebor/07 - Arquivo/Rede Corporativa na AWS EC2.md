# 🌐 Rede Corporativa na AWS EC2 & Tutorial

> [!abstract] Resumo do Projeto
> Simulação multi-instância em **Ubuntu Server** na **AWS EC2** realizada em **maio e outubro de 2026**, implementando serviços corporativos completos e portal intranet estático para a [[Equipiada Studios|Equipiada Studio]], acompanhada de **tutorial técnico em Markdown** sobre deploy com **AWS EC2, VPC e VPN**.

---

## 🛠️ Arquitetura e Serviços

| Componente | Tecnologia / Função |
| --- | --- |
| **Cloud & Rede** | AWS EC2, VPC, VPN |
| **Sistema Operacional** | Ubuntu Server (simulação multi-instância) |
| **Diretório Corporativo** | Samba4 Active Directory |
| **Proxy & Controle de Acesso** | Proxy **Squid** com filtro por grupos **LDAP** |
| **Resolução de Nomes** | DNS local |
| **Aplicação Interna** | Portal intranet estático para a [[Equipiada Studios|Equipiada Studio]] |
| **Documentação** | Tutorial técnico em Markdown sobre deploy com AWS EC2, VPC e VPN |
